# skill-

个人 Claude Code skill 收集仓库。

## 已收录

### ppt-master

AI 驱动的 PPT 生成工作流（v6.9.0）：把 PDF / Word / 网页 / Markdown 转换成原生可编辑的 PPTX，支持模板填充、美化、加旁白和动画。

- 上游仓库：https://github.com/hugohe3/ppt-master
- 许可证：MIT（LICENSE 文件随附）
- 安装方式：把 `ppt-master` 文件夹复制到 `C:\Users\<用户名>\.claude\skills\` 即可

## 使用

在 Claude Code 中重启会话后，skill 自动生效；对话中直接提出 PPT 制作需求即可触发。
